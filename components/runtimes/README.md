# Trusted Runtimes Component

A trusted runtime exists only when an authorised agent cannot safely execute through normal APIs, connectors, MCP, browser or cloud tooling.

Examples:

- VPS/SSH execution;
- isolated self-hosted runner;
- machine-local CLI/profile;
- future approved privileged execution surface.

Keep reusable HOW in Skills and current business truth in domain owners. The runtime owns execution mechanics and evidence only.
