# GitHub Component

GitHub is ARC's durable human + AI operating desk.

Use it for repository-owned architecture, Issues, Pull Requests, agent instructions, Skills distribution, automation and execution evidence.

Do not treat GitHub as the automatic owner of CRM, accounting, ATS or private-file state.

Baseline for a material repository:

```text
README.md
AGENTS.md
Issues
branch/PR path for material changes
least-privilege Actions
verification
```

Projects are useful for cross-repository portfolio visibility when they reduce manual coordination; they are not a replacement source of truth for Issue content.
