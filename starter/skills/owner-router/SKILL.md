# Owner Router

Use the smallest correct owner and start from the organisation's canonical direction.

```text
organisation North Star
→ requested need / question
→ identify information class
→ read current owner truth
→ act in that owner or route onward
→ verify real state
→ leave durable evidence where it belongs
```

Default ownership:

- organisation mission / vision / directives → declared canonical North-Star owner;
- reusable HOW → Skills canon;
- external research / proving → Research;
- business/product facts → domain owner;
- CRM/ERP/ATS/accounting state → specialist system;
- confidential documents → private file owner;
- privileged execution implementation → trusted-runtime owner;
- derived context → memory only after current canon is established.

For substantive durable work, preserve the original requested outcome separately under `Anti-Drift — Original Objective`; do not use `North Star` as another label for a task objective.

Important machine-first front doors should provide compact Fast Links to the North Star, Skills, workflow, owner/system map and Issues when those destinations are known. Do not make agents rediscover canonical paths unnecessarily.

Do not copy mutable specialist-system or private-file state into GitHub for agent convenience.
