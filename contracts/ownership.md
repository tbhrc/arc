# Ownership Contract

ARC uses **one owner per class of truth**.

Before automating a workflow, declare:

| Question | Example owner |
|---|---|
| How should this recurring work be done? | Skills canon |
| What external evidence supports this tool/decision? | Research |
| What is the current business/product decision? | domain repository |
| What is the current customer/deal state? | CRM |
| What is the invoice/payment state? | accounting system |
| Where is the confidential signed document? | private file store |
| How do we access a privileged machine/runtime? | trusted runtime owner |
| What did we learn previously? | derived memory, verified against canon |

Link across owners. Do not mirror mutable state merely for convenience.
