## What the TBHRC reference demonstrates

TBHRC's current organisation-level **North Star** is the Canonical Top Five Directives exposed through the AI Sniper Entry Map. That is a worked example of ARC's North-Star mechanism, not wording that generic ARC deployments should inherit.

A mature ARC estate may separate:

- an organisation-level North Star / mission / directives owner;
- shared Skills;
- machine-first routing and Fast Links;
- durable GitHub Issues carrying **Anti-Drift — Original Objective** for specific work;
- Research;
- business/domain hubs;
- revenue/lead/recruitment systems;
- public websites;
- privileged runtime infrastructure;
- private files and specialist systems;
- derived memory;
- learning/course material.

The important distinction is:

```text
North Star = organisation-level direction
Anti-Drift = original requested outcome of one durable work item
```

Do not copy TBHRC's repository names, Top Five wording or specialist-system choices into another business unless they genuinely match that organisation. ARC should reproduce the mechanism and ownership boundaries; each target organisation owns its own mission wording and live system choices.
