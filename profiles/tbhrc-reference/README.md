# TBHRC Reference Profile

This profile documents the live architecture that produced ARC at a high level. It is **reference wiring**, not a backup of Talent Bridge/iMPLEMENTAi business data.

Use it to understand how a mature ARC estate may separate:

- shared Skills;
- Research;
- business/domain hubs;
- revenue/lead/recruitment systems;
- public websites;
- privileged runtime infrastructure;
- learning/course material.

Do not copy these repository names into another business unless they genuinely match that business's domains.
